# 审核规则清单区域：默认折叠 + 「查看规则」抽屉

日期：2026-08-11
模块：前端 `frontend/src/components/RulePanel.tsx`、`frontend/src/index.css`

## 需求回顾
1. 默认仅展示规则总数量（如「共 N 条规则」），不展开具体规则。
2. 提供明确触发按钮（「查看规则」），点击弹出抽屉/弹窗，展示完整规则配置：名称、条件、状态等明细。
3. 视觉与交互严格遵循 Ant Design 设计规范（组件选型、间距、圆角、配色、图标），统一、易用、响应式。

## 实现方案

### 默认折叠态（`RulePanel` Card 主体）
- 一行式 `rule-summary-bar`：`共 N 条规则`（加粗主色文字）+ `已选 M 条`（次要灰字）+ 主按钮「查看规则」。
- 不渲染任何具体规则内容，界面保持极简。

### 「查看规则」抽屉（Ant Design `Drawer`）
- 标题区：`FileTextOutlined` 图标 + 文案 + 蓝色 `Tag` 显示总数。
- 宽度自适应：桌面 `520px`；`window.innerWidth < 768` 时 `100%` 全屏（resize 监听）。
- 顶部摘要行：总数 / 已选数 + `全选` / `清空` 操作（`rulesets.length>1` 时显示规则集切换 `Select`）。
- `Input.Search` 搜索框（按名称/说明实时过滤）。
- `Empty` 空态（无匹配或无规则）。
- 按类别分组（资格性/商务/技术/格式/一致性/法规…），每组头部显示「已选 x/y」与「全选本组/取消本组」。
- 每条规则为一行可点击卡片，包含：
  - `Checkbox`（点击切换选中，行点击亦可，键盘 Enter/Space 支持）
  - 规则名称（加粗）
  - 严重级别 `Tag`（否决项=红 / 重要=橙 / 一般=蓝 / 提示=默认）
  - 状态 `Tag`（启用=绿 / 停用=默认）+ 「需法规依据」蓝色 `Tag` + 选中态勾选图标
  - 规则说明（条件）+ 审核要点（分号连接）
- 抽屉右上角「新增规则」按钮，复用原有新增/编辑 `Modal`。

### 设计令牌对齐（Ant Design v5）
- 主色 `#1677ff`；圆角 `8px`；文字 `rgba(0,0,0,.88)` / `.65`。
- 间距采用 antd 8/12/16 节奏；图标 `UnorderedListOutlined` / `FileTextOutlined` / `PlusOutlined`。
- 选中态：浅蓝底 `#f0f7ff` + 主色边框与内描边阴影。
