# 接口文档页面完善（/api/docs 增强）

> 增强现有 FastAPI 自动生成的 Swagger 文档页（`/api/docs`，对应 `/api/openapi.json`），
> 为全部 19 个路由模块、45 个主要接口补充「贴近真实业务」的请求/响应示例，
> 并在文档顶部新增「枚举值 / 常量取值速查表」。

## 一、根因：为什么原文档是空的

- 项目 89+ 接口中有 **10 个直接用 `payload: dict` 裸字典**作入参（rules/files/sections/legalrules 等），
  另外多数接口的返回值是裸 `dict` → Swagger 里请求体/响应体都是 `{}`，无任何字段说明与示例。
- Pydantic 模型（ReviewRequest / Rule / Finding / UploadedFile 等）虽有字段，但**未写 description/example**，
  Schema 只有字段名，无中文释义、无示例取值。

## 二、实施方案（零侵入，不改任何路由业务逻辑）

新增 `backend/openapi_enrich.py`，仅对 `app.openapi()` 生成的 schema 做后处理：

1. **枚举速查表**：`ENUM_REFERENCE`（Markdown）追加到 `info.description`，文档页顶部即可见。
2. **接口示例**：`EXAMPLES` 用 builder 函数 `reg()` 构造（避免手工嵌套括号出错），
   按 `path → method` 注入 `requestBody` / `responses` 的 `examples`（贴近真实业务数据：
   规则名用「中标价与暂估价异常接近」、文件名「评标报告.docx」、金额 172.7 万元等）。
3. `main.py` 挂载 `custom_openapi`，在 schema 生成后调用 `enrich_openapi` 并缓存。

### 枚举覆盖（速查表章节）
`mode`(bid/tender/general)、`role`(tender/bid/attachment/legal)、`status`(pass/fail/warn/unknown)、
`category`(8 类)、`severity`(critical/major/minor/info)、`task.status`(pending/running/completed/failed/cancelled)、
`legal-rules.status`(pending/mining/ready/failed)、`judgment`(adopt/reject)、`FileValidation.level`(ok/warn/error)、
`role`(admin/user)、`scopes`(review/feedback/kb/audit/rules/settings/*)、`ocr_provider`(tuling/baidu/xfyun)、
一致性核查结论语义（inconsistency_rate / rule_drifted / deterministic_ratio）。

### 示例覆盖（45 个接口操作，跨 19 个模块）
auth(login/register/me)、files(upload/列表/role/type)、review(tasks 创建/详情/列表/stream)、
rulesets(新建/by-mode/consistency-elements/consistency-preview)、legal-rules(generate/列表/详情/promote)、
sections、file-types、rule-groups、feedback(提交/列表/校验集)、prompts(更新/测试/重置)、
settings(查询/更新/测试/KB 列表)、reviewdata(记录/详情/决策/verify/lookup)、
audit(consistency/records)、call_audit(calls/ai-calls/call-stats)、export(report)、admin(tasks/feedback)。

- 关键抽样：
  - `POST /api/rulesets` 请求体注入示例「新建自定义规则集（含确定性与 LLM 规则）」，
    含 `structured.amount_pair_diff` 相对阈值写法，便于照抄。
  - `GET /api/audit/consistency` 响应示例含 `inconsistency_rate / rule_drifted / deterministic_ratio`。

## 四、使用方式（对开发者/调用方）

1. 启动后端后访问 `http://<host>:<port>/api/docs`（本机 9100）。
2. 每个接口展开后：
   - **请求示例**：在「Request body」区点 Example Value 下拉，选演示示例。
   - **响应示例**：在「Responses」区展开对应状态码，点 Example Value。
   - **枚举说明**：页面顶部「枚举值 / 常量取值速查表」章节。
3. 非 Swagger 调用方可直接拉 `GET /api/openapi.json` 作为机器可读契约。
